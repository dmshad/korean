# 2. ПРИМЕЧАНИЯ К ПРОИЗНОШЕНИЮ (нестандартные чтения)

- 학생 → [학쌩] хаксэнъ (경음화: 생 → 쌩 после 받침 ㄱ)
- 학교 → [학꾜] хаккё (경음화: 교 → 꾜 после 받침 ㄱ)
- 식당 → [식땅] сиктанъ (경음화: 당 → 땅 после 받침 ㄱ)
- 있다 → [읻따] итта (받침 ㅆ → ㄷ + 경음화)
- 없다 → [업따] опта (겹받침 ㅄ → ㅂ + 경음화)
- 먹다 → [먹따] мокта (경음화 после 받침 ㄱ)
- 마시다 → мащида (ㅅ перед [i] → щ)
- 신문 → щинмун (ㅅ перед [i] → щ)
- 옷 → [옫] от (финальный ㅅ → [т])
- 한국어 → [한구거] хангуго (связывание 국 + 어)
- 회의 → [회이] хвеи (ㅢ в неначальной позиции → [i])
- 일하다 → ирхада (ㅎ ослабляется после ㄹ)
- 말하다 → мархада (ㅎ ослабляется после ㄹ)
- 영화 → йонъхва, в беглой речи ближе к [영와] (ㅎ ослабляется между сонорной и гласной)
- 좋다 → [조타] чжотха (격음화: ㅎ + ㄷ → ㅌ)
- 작다 → [작따] чжактта (경음화 после 받침 ㄱ)
- 많다 → [만타] манта (ㄶ + ㄷ → ㄴ + ㅌ, 격음화)
- 적다 → [적따] чжокта (경음화 после 받침 ㄱ)
- 맛있다 → [마싣따] мащитта (связывание 맛 + 있; 시 → щи; допустимо и [마딛따])
- 새롭다 → [새롭따] сэроптта (경음화 после 받침 ㅂ)
- 짧다 → [짤따] тчальтта (겹받침 ㄼ → ㄹ + 경음화)
- 쉽다 → [쉽따] щвиптта (경음화 после 받침 ㅂ; 쉬: ㅅ → щ перед [wi], глайд в сохраняется → щви)
- 어렵다 → [어렵따] орёптта (경음화 после 받침 ㅂ)
- 읽다 → [익따] икта (겹받침 ㄺ → ㄱ + 경음화)
- 듣다 → [듣따] тытта (경음화 после 받침 ㄷ)
- 걷다 → [걷따] котта (경음화 после 받침 ㄷ)
- 점심 → чжомщим (ㅅ перед [i] → щ)
- 쉬다 → щвида (ㅅ → щ перед [wi])
- 셋 → [섿], 넷 → [넫], 다섯 → [다섣], 여섯 → [여섣] (финальный ㅅ → [т])
- 여덟 → [여덜] йодоль (겹받침 ㄼ → ㄹ)
- 쉰 → щвин (ㅅ → щ перед [wi])
- 일흔 → ирхын (переход ㄹ + ㅎ в принятой проектной транскрипции)
- 십만 → [심만] щимман (비음화: ㅂ → ㅁ перед ㅁ)
- 백만 → [뱅만] пэнъман (비음화: ㄱ → ㅇ перед ㅁ)
- 잡지 → [잡찌] чжапччи (경음화 после 받침 ㅂ)
- 접시 → [접씨] чжопщи (경음화 после 받침 ㅂ; ㅅ перед [i] → щ)
- 전화 → [저놔] чжонва (ㅎ ослабляется после ㄴ, связывание)
- 별로 → [별로] пёлло (유음화: ㄹ + ㄹ, долгий ㄹ)
- 운전하다 → унджонхада (ㅈ озвончается между сонорной и гласной)
- 전화번호 → чжонхвабонхо (ㅂ озвончается после гласной; ㅎ ослабляется)
- 할아버지 → [하라버지] харабоджи (связывание 받침 ㄹ + 아)
- 이웃 → [이욷] иут (финальный ㅅ → [т])
- 의사 → ыйса (ㅢ в начальной позиции сохраняется как [ый])
- 딸 → тталь (напряжённый ㄸ; финальный ㄹ → ль)
- 계란 → [게란] керан (ㅖ в сочетании с согласной → [е])
- -습니다 / -ㅂ니다 → [씀니다 / ㅁ니다] (비음화: ㅂ → ㅁ перед ㄴ; после 받침 ㅂ ещё и 경음화 ㅅ → ㅆ):
  감사합니다 [감사함니다], 죄송합니다 [죄송함니다], 실례합니다 [실레함니다],
  반갑습니다 [반갑씀니다], 고맙습니다 [고맙씀니다]
- -겠습니다 → [겓씀니다] (ㅆ → [т] перед ㅅ, 경음화, 비음화): 알겠습니다 [알겓씀니다],
  처음 뵙겠습니다 [처음 뵙껟씀니다], 잘 먹겠습니다 [잘 먹껟씀니다]
- 잘 먹었습니다 → [잘 머걷씀니다] (связывание 먹 + 었; ㅆ → [т], 경음화, 비음화)
- 안녕히 → [안녕이] аннёнъи (ㅎ ослабляется между сонорной и гласной)
- 계세요 → [게세요] гесэё (ㅖ после согласной → [е])
- 괜찮아요 → [괜차나요] квэнчханаё (ㄶ: ㅎ выпадает перед гласной, ㄴ связывается)
- 실례 → [실레] щилле (ㅖ после согласной → [е]; ㄹ + ㄹ — долгий ㄹ)
- 잠깐만요 → [잠깐만뇨] чжамкканманнё (ㄴ-첨가: вставка ㄴ перед 요)

Остальные слова читаются по стандартным правилам.

# 3. СЕМАНТИЧЕСКИЕ ЗАМЕТКИ

- 식당 — место, где ЕДЯТ (столовая, ресторан). Русское «кафе» в значении «недорогая едальня» = 식당, НЕ 카페.
- 카페 — место, где ПЬЮТ кофе/чай. Еда — только десерты.
- 밥 — варёный рис / приём пищи («поесть»). 음식 — еда как категория (한국 음식).
- 일 — работа как дело/занятие. 회사 — фирма как место работы.
- 회의 — деловая встреча, совещание. 만나다 — встречаться с человеком.
- 차 — омоним: «чай» и «машина». Различаются по контексту.
- 일 — омоним: «работа, дело», «1» (한자어) и «день / число месяца».
- 이다 — связка «являться кем/чем». 있다 — «иметься, находиться». Разные глаголы.
- 형용사 (좋다, 크다 и т.д.) — «глаголы-прилагательные»: сами являются сказуемым, спрягаются как глаголы, связка 이다 НЕ нужна.
- 많다/적다 — 형용사 «много/мало» (сказуемое). Наречие «много» (많이) — отдельное слово, пока не изучено.
- 맛있다 = 맛 «вкус» + 있다; спрягается по 있다 (맛있어요).
- 아주 — наречие степени, ставится перед 형용사: 아주 크다 «очень большой». Само не спрягается, сказуемым не является.
- 새롭다, 쉽다, 어렵다 — 형용사 на ㅂ-основу (ㅂ-불규칙).
- 길다, 알다, 만들다 — основы на ㄹ (ㄹ выпадает перед рядом окончаний).
- 모르다, 빠르다 — 르-불규칙. 듣다, 걷다 — ㄷ-불규칙. 쓰다, 바쁘다, 아프다, 나쁘다, 크다, 예쁘다 — ㅡ-основы.
- 쓰다 — омоним: «писать» и «использовать» (позже добавится «горький»).
- 아침/점심/저녁 — двойное значение: часть суток И приём пищи в это время.
- 오늘/어제/내일/지금 — употребляются БЕЗ частицы 에. 아침/점심/저녁/밤 — с 에.
- Составные числительные образуются сложением и отдельными словами НЕ считаются: 고유어 열 + единица (열하나, 열둘 … 열아홉), 스물하나, 서른둘 и т.д.; 한자어 십 + единица (십일, 십이 … 십구), 이십, 삼십.
- 한자어 vs 고유어 — две параллельные системы счёта. Выбор зависит от счётного слова, не от размера числа.
- Выше 99 исконных числительных не существует: со 100 работает только 한자어 (백, 천, 만).
- 영 — «ноль»; 공 — «ноль» в номерах и кодах.
- 얼마 — «сколько; сколько стоит»; 몇 — «сколько» о количестве.
- 분 — «минута» и уважительный счётчик людей.
- Корейские разряды группируются по ЧЕТЫРЕ знака, а не по три: 만 (10⁴) — самостоятельный разряд, дальше счёт идёт от него (십만, 백만, 천만). Русское «сто тысяч» = 십만, «миллион» = 백만.
- Перед 백/천/만 единица не произносится: 100 = 백 (не 일백), 10 000 = 만 (не 일만). Но 십만, 백만 — с множителем.
- 개 — омоним: «собака» и счётчик предметов «штука». Собак при этом считают через 마리, не через 개.
- 공 — омоним: «мяч» и «ноль» в номерах.
- 잔 — посуда для питья И счётчик порций напитка (커피 한 잔). 컵 — заимствованная чашка/стакан как предмет.
- 병 — «бутылка» как предмет; позже работает и как счётчик бутылок.
- 전화 — «телефон» и «телефонный звонок».
- 번 после 고유어 = «раз» (한 번, 두 번); после 한자어 = «номер» (일 번, 이 번). Система счёта меняет значение.
- 도 и 만 ВЫТЕСНЯЮТ 은/는, 이/가, 을/를 (밥도, 저만), но НЕ вытесняют 에/에서 — те сохраняются перед ними: 방에도, 저녁에만, 회사에서도.
- 도 цепляется к добавляемому элементу: 저도 술을 안 마셔요 («я тоже») vs 저는 술도 안 마셔요 («и алкоголь тоже»).
- 도…도 + отрицание = «ни… ни…»: 남자도 여자도 몰라요. Без отрицания — «и то, и другое».
- 하고 / 와 / 과 — одна частица на два значения: «и» (перечисление) и «с» (совместное действие). Различается по глаголу.
- 와/과 — письменные, выбор ОБРАТНЫЙ привычному: 받침 нет → 와 (친구와), 받침 есть → 과 (선생님과). 하고 — разговорное, от 받침 не зависит.
- Частица перечисления ставится только на последнее слово группы: 빵하고 우유를 샀어요.
- 알다 ↔ 모르다 — пара слов, как 있다 ↔ 없다. «Не знаю» = 몰라요, а НЕ 안 알아요.
- Номер комнаты/этажа читается как целое число (방 번호가 이백칠이에요), телефон — по цифрам (공일공 오삼팔).
- 전혀 и 별로 употребляются ТОЛЬКО с отрицанием. 전혀 — категорический ноль («вообще ни капли»). 별로 — смягчённое «не особо, не очень», НЕ «не совсем».
- 자주/가끔/항상 — свободные наречия, ставятся перед сказуемым. Неизменяемые: формы на 다 у них нет.
- 하다-глаголы (운동하다, 청소하다, 요리하다, 운전하다, 전화하다): именная часть остаётся существительным и может отделяться — 요리를 하다, 한국 요리를 하다. Отрицание 안 встаёт МЕЖДУ частями: 청소 안 해요.
- 고기 — «мясо» шире русского: плоть животного вообще. 물고기 — живая рыба, 생선 — рыба как еда.
- 채소 (한자어, письменный, TOPIK) = 야채 (разговорный). Смысл один, регистр разный.
- 담배 + 피우다 — устойчивая пара. 피우다 отдельно почти не употребляется.
- 술 — алкоголь как категория, не конкретный напиток. Глагол — обычное 마시다.
- 형/누나 vs 오빠/언니 — выбор зависит от пола ГОВОРЯЩЕГО, а не адресата: мужчина говорит 형/누나, женщина — 오빠/언니.
- 동생 — младший сиблинг без различия пола. Уточнения 남동생/여동생 пока не изучены.
- 엄마/아빠 — разговорные, внутрисемейные. 어머니/아버지 — нейтрально-вежливые, при посторонних.
- 님 — суффикс вежливости к лицу: 선생님, 사장님, 손님. Без него формы звучат грубо.
- 회사원 = 회사 «фирма» + 원 «работник, член». Продуктивный корень 원.
- 손님 — и «гость» в доме, и «клиент» в заведении. Одно слово на оба смысла.
- Омонимичные слоги в 한자어: 전 — «электричество» (전화), «вращать, поворачивать» (운전), «перед» (오전). 화 — «речь» (전화), «изображение» (영화). 영 — «проецировать» (영화), «ноль» (числительное). Слог не равен корню.
- Этикетные формулы заучиваются целиком, как слова. Окончания в них (합니다-форма, -(으)세요)
  разбираются задним числом в темах 20 и 25; отдельно от формул пока не употребляются.
- 안녕히 가세요 / 안녕히 계세요 — выбор по тому, кто уходит: уходящему — 가세요 («идите спокойно»),
  остающемуся — 계세요 («оставайтесь спокойно»). Расходятся оба — оба говорят 가세요.
- 감사합니다 (한자어) и 고맙습니다 (исконное) — оба вежливые, взаимозаменяемы. 고마워, 미안해 —
  반말: только близким и младшим. Старшему и незнакомому — 고맙습니다 / 죄송합니다.
- 죄송합니다 — за уже случившееся (вина, неудобство). 실례합니다 — ДО того, как побеспокоить
  (обратиться, войти). 잠깐만요 — «минутку» и «дайте пройти».
- 잘 먹겠습니다 / 잘 먹었습니다 — говорит САМ едящий (до / после еды), тому, кто готовил или
  угощает. Русское «приятного аппетита» другому — не аналог.

# 6. СЛАБЫЕ МЕСТА

Сюда заносится только системное: ошибка повторилась минимум дважды в разных блоках,
либо это устойчиво неверный выбор формы. Опечатки и единичные описки НЕ заносятся.
Снимается после 3 верных ответов подряд в разных блоках.
В сериях — 2–3 раза за серию, не в каждом блоке.

- **Потеря 에/에서 перед 도/만.** Пропущено 4 раза в разных блоках серии темы 14
  (회사도, 저것도, 저녁만, 방도 вместо 회사에서도, 저기에도, 저녁에만, 방에도).
  Проверка: если без 도/만 слово стояло с 에/에서 — они остаются.
- **Запись произношения вместо написания.** 머거요 (×2), 이써요, 한구거 вместо
  먹어요, 있어요, 한국어. 받침 звучит в следующем слоге, но пишется на своём месте.

## Плохо помню

Слова, при ответе на которые ученик подсматривал (ставит ' после ответа).
Вносятся при закрытии темы. Приоритет в сериях. Снимаются после 2 верных ответов без '.

병 — пёнъ — бутылка
적다 — чжокта [적따] — мало, немногочисленный
항상 — хансанъ — всегда

# 7. ПРОГРЕСС

```
% курса = пройденные темы / все темы курса × 100
```
Тема — любой шаг курса: словарная, грамматическая, практикум, дополнительная — все на равных.
Текущая (в процессе) не считается. Всего тем — по курсу в артефакте (сейчас **90**); добавится
практикум или доп. тема — знаменатель растёт. Слова считаются отдельно, справочно.
(До 03.10 формула была: слова/800 × 50 + темы/46 × 50.)

**Текущее состояние: 21 из 90 тем → 23%** · 234 слова (текущая — грамматика 15)

Расчёт: 21 / 90 × 100 = 23.3 ≈ 23%. Пройдено 21 шаг курса: база, грамматика 1–14 (14),
словарные блоки 1–4, 5–8, 9–12 и словарные темы 10, 11 (5), практикум 1.

Подсчёт слов: по записям реестра. Омонимы считаются РАЗНЫМИ словами —
одинаковое написание не даёт знания второго значения (일 ×3, 이 ×2, 차, 쓰다, 분).

## Ритм

- Норма: 800 слов ÷ 46 тем ≈ **17 слов на грамматическую тему** (с доп. темами словаря к концу курса — 939 слов).
- Сейчас: 234 ÷ 14 = 16.7 — почти норма (17). Порцию держать на 20.
- Решено 01.10: словарная тема (20 слов) перед каждой грамматической темой с 16 по 46 → 234 + 31 × 20 ≈ 854.
- С фазы 2 порцию придётся увеличивать сильнее: грамматика исчерпывается быстрее лексики.
